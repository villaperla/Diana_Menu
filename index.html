✏️ Editor del menú

Conecta con tu token de GitHub para editar el data.json del repositorio.

¿Cómo funciona? (ayuda)
  1. Crea un token: github.com/settings/tokens (classic con scope repo, o fine-grained con permiso Contents: Read and write sobre tu repositorio).
  2. Este index.html debe estar publicado con GitHub Pages en ese repositorio.
  3. Al guardar, el editor hace commit del archivo data.json en la ruta indicada (lo crea si no existe).
  4. La página lee data.json desde la raíz ("/") en cada carga; si no existe, muestra el menú integrado.
  5. El token queda guardado solo en este navegador (localStorage). Usa "🚪 Salir" para borrarlo.
